My entry for the [make.fun bounty "One Line, No Deadline Met"](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce?ref=r2d6z7t8): one single-line joke, an excuse for missing a deadline, and nothing else.

## The excuse

> My calendar says the deadline was Friday. My brain says Friday is a feeling, not a date. My brain won.

102 characters, one line, no picture, no link, no second line.

## Running it

`main.py` checks the line against the competition gate (1–200 characters,
single line, no leading or trailing whitespace) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, defaulting to `/output/entry.txt`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
cat /tmp/out/entry.txt
```
